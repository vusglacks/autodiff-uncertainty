# 자동 미분을 이용한 실험 불확도 자동 계산기

계산식과 측정값·불확도를 입력하면, 각 변수의 편미분을 자동으로 구해
오차 전파 공식으로 최종 불확도를 계산하는 웹 프로그램입니다.

자료구조와 알고리즘 수업 프로젝트 · 2307 송하율

## 해결하려는 문제

실험 보고서에서 결과의 불확도를 구하려면 계산식을 각 측정 변수로 편미분해야 합니다.

```
u_c(f) = √( Σ ( ∂f/∂xᵢ · u(xᵢ) )² )
```

식이 조금만 복잡해져도 이 과정을 손으로 반복해야 해서 시간이 오래 걸립니다.
이 프로그램은 임의의 수식에 대해 편미분을 자동으로 구해 이 과정을 없앱니다.

## 사용한 자료구조와 알고리즘

| 단계 | 방법 |
|---|---|
| 수식 → 구조 | **재귀 하강 파싱**으로 수식 문자열을 **계산 트리**로 변환 |
| 편미분 계산 | **전진 모드 자동 미분** — 트리를 한 번 순회하며 값과 모든 편미분을 동시에 계산 |
| 계산 과정 표시 | **기호 미분** — 미분 규칙대로 트리를 변환하고 식을 정리해 편미분 *식*을 보여줌 |
| 검증 | **중앙 차분 수치 미분**으로 같은 값을 구해 자동 미분 결과와 비교 |

### 왜 자동 미분인가

- **수치 미분**은 변수가 n개면 함수를 2n번 계산해야 하고, 미소 변화량 h에 따라 오차가 생깁니다.
- **기호 미분**은 정확하지만 미분한 식이 기하급수적으로 길어질 수 있습니다.
- **자동 미분**은 트리를 한 번만 순회하면서도 정확한 값을 줍니다.

## 기능

- 수식을 입력하면 변수를 자동으로 찾아 측정값·불확도 입력칸 생성
- 유효숫자를 맞춘 `값 ± 불확도`와 상대불확도
- 변수별 오차 기여도 — 어느 측정이 오차를 지배하는지 표시
- 편미분 표와 수치 미분 대조 검증
- 계산 트리 보기
- 계산 과정 펼쳐 보기 (편미분 식 → 불확도 곱 → 제곱합의 제곱근 → 유효숫자)
- 삼각함수 각도 단위(도/라디안) 선택

지원 연산 `+ - * / ^`, 함수 `sin cos tan asin acos atan exp ln log sqrt abs`, 상수 `pi e`

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 설치할 것은 없습니다.

## 테스트

```
npm test
```

손으로 계산한 편미분값·유효숫자 처리·오류 처리 21개와
기호 미분으로 구한 편미분 식 7개를 확인합니다.
